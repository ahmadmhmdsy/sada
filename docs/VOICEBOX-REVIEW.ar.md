# مراجعة Voicebox مقابل صدى — مجلس القياس

**المنهج:** مجلس القياس، الوضع C المدمج (قياس سببي + مجلس خصومة + حكم المفتي).
**التاريخ:** 16 تشرين الثاني/نوفمبر 2026 (بغداد) · **القيد الحاكم:** صدى تطبيق عربي أولاً، يعمل دون
إنترنت، على ويندوز، بلا قياسات ولا تحديث تلقائي ولا حساب ولا مرحّل هاتف، وبرخصة MIT، وبلا نصوص واجهة
مكتوبة خارج كتالوجات الترجمة.

**المصدران:** [Voicebox](https://github.com/jamiepine/voicebox) برخصة MIT عند الالتزام
**8af7efe62fab8d33e2a5dfbedabaa45f68a5184f**، وصدى عند الإصدار 3.2.2 مع عمل 3.3.0. النسخة الكاملة
بالإنكليزية في [VOICEBOX-REVIEW.md](VOICEBOX-REVIEW.md)؛ هذه خلاصة عربية.

## ما وجدناه في Voicebox

- تطبيق TTS محلي: ثمانية محركات نطق، ثلاث وعشرون لغة، استنساخ صوت، مؤثرات، محرر قصص، سجل صوتي،
  حبة إملاء، تحسين نصوص بنماذج لغوية، وخادم MCP وواجهة REST محلية على 127.0.0.1:17493.
- العربية تصل إليه عبر ثلاثة محركات فقط: Chatterbox Multilingual وTADA 3B وOmniVoice؛ وأوزان
  OmniVoice برخصة CC-BY-NC لا يمكن شحنها في تطبيق حر الترخيص.
- دروس من عيوبه: اللصق على ويندوز ما زال في خارطة الطريق، والواجهة إنكليزية فقط، وخلط المحركات
  والعتاد فيه ثغرات، والطلب #603 يُظهر أن تحسين النصوص يحوّل غير الإنكليزية إلى إنكليزية افتراضياً،
  والمسألة #778 تكشف تعرّض الواجهة المحلية لخداع إعادة توجيه DNS، وحكاية عملة $VOICEBOX تذكير بأن
  ضجيج أدوات الوكلاء قد يسبق المنتج نفسه.

## ما كان في صدى قبل 3.3.0

صدى يملك أصلاً واجهة HTTP محلية (منفذ عشوائي، مغلقة افتراضياً، والعنوان يُكتب في الإعدادات أثناء
التشغيل)، ومهارة وكيل مثبّتة لـ Claude Code وCodex، وواجهة سطر أوامر للمحرك، ونصوصاً محفوظة كملفات
مقروءة. أي أن الوكلاء يستطيعون الوصول إلى صدى، لكن عبر خطوة إعداد: تشغيل الواجهة ومعرفة المنفذ، أو
معرفة مسار المحرك والنموذج وأعلامه.

## جدول الأحكام

| المرشح | الحكم | العلة الحاكمة |
| --- | --- | --- |
| خادم MCP داخل Sada.exe | **نجا وشُحن** | يلغي فئة خطأ الإعداد (منفذ/مفتاح/مسار) بلا شبكة ولا نصوص واجهة. |
| تسمية مهارة الوكيل sada وتوثيق MCP فيها | **نجا وشُحن** | الوكيل يجب أن يجد صدى باسمه، لا باسم Vibe. |
| ثمانية محركات نطق | **دُرئ** | العربية في محركين أو ثلاثة، وأحدها غير تجاري، والحجم والعتاد والصيانة هي الكلفة الحقيقية. |
| استنساخ الصوت | **دُرئ** | الموافقة والانتحال، ولا دليل جودة عربية. |
| المؤثرات ومحرر القصص | **دُرئ** | لا مخرج TTS في صدى لتصقله، ونطاق منتج آخر. |
| السجل الصوتي وحبة الإملاء واللصق على ويندوز وإدارة النماذج | **موجود أصلاً** | صدى يحفظ نسخة الصوت مع النص، ويعرض حبة الإملاء، ويلصق عبر النظام، ويدير النماذج بالتحقق. |
| ربط صوت لكل تطبيق | **معلّق** | يتوقف على وجود أصوات. |
| تحسين النصوص افتراضياً بنموذج محلي | **خُفّض** | الملخصات الاختيارية بمفتاح المستخدم تبقى؛ لا افتراضي ولا نموذج مرفق. |
| التحقق من Host/Origin في الواجهة المحلية | **درس متابعة** | صدى يحتاج تدقيقاً أمنياً مماثلاً لمسألة #778. |
| واجهة إنكليزية أولاً، أو عملة/تسويق على أدوات الوكلاء | **يُجتنب** | يخالف القيد أو يستبدل المنتج بالضجيج. |

## اختبار الإبطال (الخطوة صفر)

الخطة تموت إذا صحّ أحد هذه: (1) تعذّر على Sada.exe --mcp الكلام عبر الأنابيب بلا طرفية؛ (2) تعذّر
حل النموذج أو المحرك بلا بيئة الواجهة؛ (3) سرّبت أداة إعدادات أو فتحت منفذاً؛ (4) تعذّر مشاركة
المنظّف العربي مع Rust؛ (5) خالف أي ثابت عربي أولاً. **كلها لم تصح**، فمضت الخطة.

## خطة 3.3.0 التي شُحنت

1. نواة MCP في **mcp/mod.rs**: JSON-RPC عبر stdio، تفاوض إصدارات 2025-06-18 و2025-03-26 و
   2024-11-05، تعليمات عربية أولاً في initialize، ping وtools/list وtools/call، أخطاء بروتوكول.
2. الأدوات في **mcp/tools.rs** و**mcp/transcripts.rs**: sada_transcribe وsada_transcripts و
   sada_transcript وsada_info، مع حل الإعدادات والنموذج والمحرك وFFmpeg والمجلد، وأزمنة
   HH:MM:SS.mmm، ورسائل خطأ عملية.
3. توأم عربي في **arabic.rs**: نفس قواعد TypeScript ونفس الاختبارات.
4. نقطة الدخول: **Sada.exe --mcp** قبل أي إعداد واجهة، مع **--config** للاختبارات.
5. سطح الوكيل: إعادة تسمية مهارة الوكيل إلى sada وتقديم تسجيل MCP على الخادم المحلي.
6. الربط: مسار تثبيت المهارة ومعالجات المحاكاة، وروابط التطبيق إلى مستودع صدى.
7. التوثيق: هذا الملف و[AGENT-MCP.ar.md](AGENT-MCP.ar.md) وملاحظات الإصدار وتحديث README
   وAGENTS والموقع وllms.txt عند 3.3.0.

## مقاييس الاستمرار والإيقاف

**استمر** إن صار إعداد MCP أول طريق أو ثانيه يذكره المستخدمون خلال إصدارين، وظهر سيناريو حقيقي
واحد على الأقل (اجتماع، إملاء عربي، تفريغ مشاريع) عبر MCP، وبقي كود MCP تحت نحو 1500 سطر بلا
تبعيات جديدة، ولم يتطلب البروتوكول تغييراً كاسراً.

**أوقف أو أخّر** إن لم يُستخدم بعد إصدارين، أو احتاج عملية ثانية أو نقلاً شبكياً ليكون مفيداً، أو
صار إبقاء عقد الأدوات الأربع أغلى من الواجهة المحلية والمهارة معاً.

**لا** نقايض أي ثابت عربي أولاً بميزة على طريقة Voicebox: لا أوزان غير تجارية، ولا افتراضيات
إنكليزية، ولا خادم دائم، ولا قياسات.

## المخاطر وعلاجها

| الخطر | العلاج |
| --- | --- |
| انحراف البروتوكول بين العملاء | تفاوض على إصدارات معروفة والعودة للأقدم، وأقل مجموعة طرق ممكنة. |
| تفريغ طويل يعلّق نداء الأداة | طلب واحد في كل مرة بالتصميم، وتوثيق المدد المتوقعة. |
| مسارات وسائط خاطئة | رفض صريح برسالة تشرح الخطوة التالية بدل آثار مكدس. |
| إعدادات من ملفات Vibe قديمة | قراءة المجلدات القديمة كاحتياط، مع --config وSADA_CONFIG_PATH. |
| تعرّض الواجهة المحلية لخداع Host (#778) | مهمة تقوية أمنية لاحقة؛ MCP عبر stdio غير متأثر. |
| عودة الزحف نحو TTS | اختبار التعليق صريح؛ لا إعادة فتح إلا بدليل ترخيص وجودة. |

## أول خطوة (تمّت)

لم تكن ورقة: بل **Sada.exe --mcp** يجيب إطار initialize في عملية حقيقية بنموذج حقيقي، ثم تجيب
الأدوات الأربع عبر الأنابيب. هذا دليل الخطوة صفر الذي بُنيت عليه المراجعة.
