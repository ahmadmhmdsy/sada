# جرد الاتصالات الشبكية

هذا المستند يسرد كل مسار اتصال خارجي في صدى 3.9.0، وما الذي يطلقه، وما يخرج من الجهاز، وأي
مفتاح في سياسة الإدارة يمنعه. وهو المرجع لقواعد جدار الحماية واستبيانات الشراء وحزمة الضمانات
([SECURITY-WHITEPAPER.md](SECURITY-WHITEPAPER.md)).

صدى يعمل دون اتصال بطبيعته: لا قياسات ولا تقارير أعطال ولا حساب ولا تحديث تلقائي ولا مرحّل بعيد.
المسارات أدناه لا تعمل إلا عندما **يطلب المستخدم أو المسؤول** تنزيلاً أو استيراد رابط أو استدعاء
مزوّد ذكاء اصطناعي.

|---|--------|--------|----------|------------------|----------------|
| 1 | تنزيل النماذج | `huggingface.co` و`github.com` (روابط الكتالوج)، وأي رابط `https` من حقل رابط النموذج أو رابط عميق `sada://download?url=` | المستخدم يضغط **تنزيل** في كتالوج النماذج أو الإعداد أو تثبيت VAD/التفرقة تلقائياً | طلب HTTPS لملف النموذج: المضيف والمسار وترويسات TLS/HTTP القياسية. لا حساب ولا كوكيز ولا نص ولا معرّف جهاز | `offlineMode` أو `disableModelDownloads` |

والتصدير PDF/DOCX/SRT، وخادم MCP، والخادم المحلي للوكلاء (على `127.0.0.1` فقط).

## فرض سياسة الإدارة

يكتب المسؤول القيم تحت `HKLM\\SOFTWARE\\Sada\\Policy` (DWORD بقيمة `1` للتعطيل):

| القيمة | الأثر |
|--------|-------|
| `OfflineMode` | كل ما يلي، وفحص الاتصال لا يفتح مقابس بعد الآن. |
| `DisableAi` | إخفاء صفحات الذكاء الاصطناعي؛ لا يمكن إجراء أي استدعاء من الواجهة. |
| `DisableUrlImport` | إخفاء تبويب الرابط، ورفض فحص yt-dlp وتنزيله وتنزيل الوسائط. |
| `DisableModelDownloads` | إخفاء التنزيل من الكتالوج والحقل اليدوي، ورفض `download_model`، مع إبقاء النماذج المثبتة صالحة. |
| `TranscriptsDir` (SZ) | تثبيت مجلد النصوص. |

ويُقرأ أيضاً ملف JSON في `%ProgramData%\Sada\policy.json` (أو مسار `SADA_POLICY_PATH`)؛ قيم
السجل أولى والقيود تُجمع بـOR. انظر [ENTERPRISE-DEPLOYMENT.md](ENTERPRISE-DEPLOYMENT.md).

تعيد طبقة أوامر Rust قراءة السياسة عند كل إجراء محمي، فإخفاء عنصر في الواجهة ليس الحماية الوحيدة.
يبقى الفرض **داخل حدود ثقة المستخدم المحلي**: من يستطيع تعديل سجل الجهاز كمسؤول يستطيع تغيير
السياسة، ومن لا يستطيع لا يتجاوزها. الفصل القوي يحتاج صلاحيات Windows وهي مسؤولية المسؤول.

## التحقق

- اعرض السياسة السارية: الإعدادات ← الخصوصية تُظهر «تُدار بواسطة مؤسستك» عند وجود أي قيد.
- راقب الاتصالات أثناء خمول التطبيق: `Get-NetTCPConnection -OwningProcess (Get-Process Sada).Id`
  في PowerShell مرتفع الصلاحية لا يُظهر اتصالات بعيدة قائمة عند عدم وجود تنزيل أو مهمة ذكاء اصطناعي.
- جدار حماية يمنع كل الاتصالات الصادرة يُبقي التطبيق صالحاً للتفريغ المحلي والتصدير وMCP والإملاء؛
  تفشل فقط التنزيلات واستيراد الروابط واستدعاءات الذكاء الاصطناعي.

## ما لا يفعله صدى

- لا قياسات ولا تقارير أعطال ولا اتصال هاتفي بالمنزل.
- لا فحص تحديث تلقائي وقت التشغيل (المُحدِّث غير مُضمَّن؛ رابط الإصدار يُفتح في المتصفح عند الضغط فقط).
- لا حساب ولا خادم تراخيص ولا تنشيط ولا إعدادات بعيدة.
- لا ترحيل ولا تفريغ سحابي ولا رفع صوت أو فيديو أو نصوص.
- لا حزم طرف ثالث لها سلوك شبكي في إصدار الإنتاج.
