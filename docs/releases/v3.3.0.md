# صدى (Sada) 3.3.0 — الوكلاء يسمعون بالعربية

**صدى** تطبيق تفريغ صوتي وفيديو إلى نص، عربي أولاً، يعمل بالكامل على جهازك بنظام Windows
بدون إنترنت وبدون حساب. يضيف هذا الإصدار **خادم MCP** مدمجاً في ملف التطبيق نفسه، فيستطيع
الوكلاء (Claude Code وCodex وغيرهم) تفريغ الصوت وقراءة النصوص المحفوظة مباشرة، دون تشغيل خادم
ودون فتح منفذ ودون فتح نافذة التطبيق.

## التحميل

| الملف | الوصف |
| --- | --- |
| **Sada_3.3.0_x64-setup.exe** | مثبّت Windows x64 (NSIS، غير موقّع رقمياً) |
| **SHA256SUMS.txt** | بصمة SHA-256 للمثبّت |
| **THIRD-PARTY-NOTICES.md** · **NOTICE** · **LICENSE** | الترخيص والإسناد وإشعارات الأطراف الثالثة |

تحقّق من الملف بعد التنزيل:

~~~powershell
Get-FileHash .\Sada_3.3.0_x64-setup.exe -Algorithm SHA256
# قارن الناتج بسطر Sada_3.3.0_x64-setup.exe في SHA256SUMS.txt
~~~

## التثبيت

1. شغّل **Sada_3.3.0_x64-setup.exe**. التثبيت لكل مستخدم في **%LOCALAPPDATA%\Sada\** ولا يحتاج
   صلاحيات مدير.
2. **تنبيه SmartScreen:** المثبّت غير موقّع رقمياً، فقد يظهر «Windows protected your PC». اضغط
   *More info → Run anyway* فقط إذا نزّلت الملف من هذا الإصدار الرسمي وتحقّقت من بصمته.
3. افتح **صدى** من قائمة ابدأ. يفتح مباشرة بالعربية ومن اليمين إلى اليسار.
4. أول مرة: نزّل نموذج Whisper من **الإعدادات ← النماذج** (المقترح للعربية large-v3-turbo، ~1.6GB)،
   أو اختر ملف ggml موجوداً على جهازك. النموذج لا يُشحن مع المثبّت.

للترقية من 3.2.2: شغّل المثبّت الجديد فوق القديم؛ الإعدادات والمشاريع تبقى كما هي.

## ما في هذا الإصدار

- **خادم MCP عربي أولاً:** الملف **Sada.exe --mcp** يتكلم JSON-RPC عبر stdio (بلا شبكة وبلا منفذ
  وبلا نافذة)، ويقدّم أربع أدوات:
  - **sada_transcribe** — تفريغ ملف صوت أو فيديو محلي بالنموذج المُعد، بلغة التطبيق (العربية)
    افتراضياً، مع خيار timestamps وخيار language: auto، وتنظيف عربي للنص افتراضياً.
  - **sada_transcripts** — سرد النصوص المحفوظة من الأحدث مع المسار والمعاينة.
  - **sada_transcript** — قراءة نص محفوظ (الأحدث افتراضياً) مع أزمنة ووسم متحدثين اختياريين.
  - **sada_info** — الإصدار والنموذج والمحرك وFFmpeg ومجلد النصوص ومسار الإعدادات وحالة كل ملف.
- **تسجيل بسيط:** Claude Code بأمر واحد (**claude mcp add sada -- "…/Sada.exe" --mcp**)، وCodex في
  config.toml، وأي عميل MCP بإعداد JSON. التفاصيل في [docs/AGENT-MCP.ar.md](../AGENT-MCP.ar.md).
- **إعادة تسمية مهارة الوكيل إلى sada:** مجلد التثبيت صار **.claude|.codex/skills/sada/SKILL.md**،
  والمهارة تبدأ الآن بقسم MCP وخطوات التسجيل، ثم مسار الملفات والواجهة المحلية والمحرك كبدائل.
- **توأم عربي في Rust:** نفس قواعد التنظيف العربي المستخدمة في الواجهة أُعيدت كتابتها في Rust
  لتُطبَّق على خرج MCP، باختبارات مطابقة حتى لا ينفصل التنفيذان.
- **إصلاح روابط التطبيق:** أزرار المستودع والإصدارات والخصوصية في الإعدادات تشير الآن إلى مستودع
  صدى بدل مستودع Vibe.
- **لا تبعيات جديدة ولا أحجام إضافية:** خادم MCP جزء من ملف التطبيق القائم، لا عملية مساعدة جديدة
  ولا بايثون ولا نماذج إضافية.
- **مراجعة موثّقة:** قرار إضافة MCP (وما لم نأخذه من Voicebox ولماذا) في
  [docs/VOICEBOX-REVIEW.ar.md](../VOICEBOX-REVIEW.ar.md) ونسخته الإنكليزية.

## قيود معروفة

- المثبّت غير موقّع رقمياً → تحذير SmartScreen محتمل.
- النموذج غير مضمّن ويحتاج تنزيلاً واحداً (~1.6GB للنموذج المقترح).

- استخراج نص PDF آلياً قد يشوّش داخل الكلمات رغم صحة العرض البصري.
- التطبيق Windows فقط؛ لا إصدار macOS/Linux في هذه الشوكة.

# English

**Sada (صدى)** is an Arabic-first, fully offline speech-to-text desktop app for Windows, forked
from [Vibe](https://github.com/thewh1teagle/vibe) (MIT). Version 3.3.0 adds an MCP server inside
the app executable, so agents get Arabic-first ears without a server toggle, a port or a running
window.

## Download

- **Sada_3.3.0_x64-setup.exe** — Windows 10/11 x64 installer (NSIS, unsigned)
- Verify the installer against **SHA256SUMS.txt** before running it.
- License and attribution files are attached next to the installer.

## Install

1. Run the installer. It installs per-user into **%LOCALAPPDATA%\Sada\** and does not need admin
   rights.
2. SmartScreen may warn because the installer is not code-signed; choose *More info → Run anyway*
   only for this official release after checking the SHA-256.
3. Launch Sada from the Start Menu — it opens in Arabic, right-to-left.
4. Download a Whisper model once from **Settings → Models** (suggested: large-v3-turbo, ~1.6GB) or
   pick an existing ggml file. Models are not bundled.

Upgrading from 3.2.2: run the new installer over the old one; settings and projects are kept.

## What is in this release

- **Arabic-first MCP server:** **Sada.exe --mcp** speaks JSON-RPC over stdio (no network, no port,
  no window) and exposes four tools:
  - **sada_transcribe** — transcribe a local audio/video file with the configured model, in the
    app language (Arabic) by default, with optional timestamps, language auto-detection and
    Arabic normalisation.
  - **sada_transcripts** — list saved transcripts, newest first, with paths and previews.
  - **sada_transcript** — read one saved transcript (newest by default), optional timecodes and
    speaker labels.
  - **sada_info** — version, model, engine, FFmpeg, transcripts folder, config path and whether
    each file resolves.
- **Simple registration:** one Claude Code command (**claude mcp add sada -- "…/Sada.exe" --mcp**),
  a Codex config.toml block, or generic JSON for any MCP client. See
  [docs/AGENT-MCP.md](../AGENT-MCP.md).
- **Agent skill renamed to sada:** installed at **.claude|.codex/skills/sada/SKILL.md**; the skill
  now leads with MCP registration and keeps the transcript-folder, local-API and engine-CLI routes
  as fallbacks.
- **Rust twin of the Arabic normaliser:** the same cleanup rules the UI applies are implemented in
  Rust for MCP output, with matching tests so the two cannot drift.
- **App links fixed:** repository, releases and privacy links in Settings point at the Sada
  repository instead of upstream Vibe.
- **No new dependencies and no extra size:** the MCP server is part of the existing executable —
  no helper process, no Python, no extra models.
- **Documented decision:** why MCP, and what was deliberately not taken from Voicebox, in
  [docs/VOICEBOX-REVIEW.md](../VOICEBOX-REVIEW.md).

## Verification before release

- Rust: **83** tests passing (including 19 for MCP and 9 for the Arabic normaliser).
- Frontend: **26 files / 132** tests passing (**pnpm test**, exit 0), **pnpm build** clean.
- Real end-to-end: **Sada.exe --mcp** with a ggml-tiny model and Arabic audio over pipes —
  initialize, tools/list, sada_info, sada_transcripts, sada_transcript, sada_transcribe.
- The installer is rebuilt by CI from this source; its hash is in the **SHA256SUMS.txt** attached
  to the release.

## Known limitations

- Unsigned installer (SmartScreen warning).
- Model download required (~1.6GB for the recommended model).
- Occasional silence hallucinations; acronyms and numbers may be written as words.
- MCP is stdio-only in this release: no network transport and no progress notifications yet.
- PDF text extraction may confuse automated extractors even though rendering is correct.
- Windows-only fork.
