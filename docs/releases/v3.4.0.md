# صدى (Sada) 3.4.0 — كتالوج نماذج موثّق وقدرات MCP وحماية نقطة النهاية المحلية

**صدى** تطبيق تفريغ صوتي وفيديو إلى نص، عربي أولاً، يعمل بالكامل على جهازك بنظام Windows
بدون إنترنت وبدون حساب. يقدّم هذا الإصدار كتالوج نماذج موثّقاً داخل التطبيق (ترخيص وحجم وبصمة
SHA-256 لكل نموذج)، ووعياً بقدرات النموذج في واجهة MCP (اللغات، VAD، الترجمة، التوجيه)، وتوافقاً
تلقائياً للغة والـVAD قبل تحميل أي نموذج، ويشدّد أمن المحرّك المحلي بحاجز Host/Origin للـloopback.
المحرّك الآن يُبنى من كود المستودع نفسه (vibe-server v0.6.16-sada.1) بدل ثنائي upstream المجرّد.

## التحميل

| الملف | الوصف |
| --- | --- |

| **THIRD-PARTY-NOTICES.md** · **NOTICE** · **LICENSE** | الترخيص والإسناد وإشعارات الأطراف الثالثة |

تحقّق من الملف بعد التنزيل (PowerShell):

    Get-FileHash .\Sada_3.4.0_x64-setup.exe -Algorithm SHA256
    # قارن الناتج بسطر Sada_3.4.0_x64-setup.exe في SHA256SUMS.txt

## التثبيت والترقية

1. شغّل **Sada_3.4.0_x64-setup.exe**. التثبيت لكل مستخدم في **%LOCALAPPDATA%\Sada\** ولا يحتاج
   صلاحيات مدير.
2. **تنبيه SmartScreen:** المثبّت غير موقّع رقمياً، فقد يظهر «Windows protected your PC». اضغط
   *More info → Run anyway* فقط للإصدار الرسمي بعد التحقق من البصمة.
3. الترقية من 3.3.1: شغّل المثبّت الجديد فوق القديم؛ الإعدادات والمشاريع والنماذج تبقى كما هي.

## ما في هذا الإصدار

- **كتالوج نماذج موثّق:** صفحة **الإعدادات ← النماذج** تعرض النماذج المتاحة من كتالوج مضمّن
  موثّق: الترخيص والحجم وبصمة SHA-256 واللغات، مع تنزيل يتحقق من البصمة بعد اكتماله. الإدخالات
  الأولى: large-v3-turbo وtiny (MIT) ونسخة العبرية large-v3-turbo-he (Apache-2.0). لا نموذج
  مضمّن في المثبّت.
- **وعي بقدرات النموذج:** يقرأ التطبيق واجهة المحرّك لمعرفة نوع النموذج ولغاته واشتراط VAD ودعمه
  للترجمة والتوجيه، ويقارب اللغة المختارة إلى أقرب لغة مدعومة، ويضمن وجود نموذج Silero VAD قبل
  تحميل نماذج Nemotron/Parakeet — في الإعدادات والشاشة الأولى وطابور التفريغ والاختصار العام.
- **MCP أوضح للوكلاء:** `sada_info` يعرض `model.capabilities`، و`sada_transcribe` يحوّل رموز اللغة
  ويمرّر `--translate`/`--prompt` فقط عند دعم النموذج ويحدّد VAD تلقائياً — دون فتح أي منفذ.
- **حماية نقطة النهاية المحلية:** المحرّك المرفق صار يرفض طلبات المتصفحات وإعادة توجيه DNS
  (Host غير الـloopback، أو Origin من صفحة ويب، أو غياب Host) مع بقاء طلبات التطبيق المحلية تعمل،
  ويشمل ذلك المسارات التي تغيّر الحالة. التطبيق يبدأ المحرّك صراحة على `127.0.0.1` بمنفذ عابر،
  وCI يبني المحرّك من `server/` ويشغّل اختبارات الحاجز عند كل إصدار.
- **توثيق:** `docs/MODELS.md` و`docs/MODELS.ar.md` (الكتالوج)، `docs/AGENT-MCP.md` ونسخته
  العربية (القدرات واللغات)، `SECURITY.md` (حدّ المحرّك المحلي وحدوده المتبقية)، و`docs/UPSTREAM-PATCHES.md` §9.

# English

**Sada (صدى)** is an Arabic-first, fully offline speech-to-text desktop app for Windows, forked
from [Vibe](https://github.com/thewh1teagle/vibe) (MIT). Version 3.4.0 adds a bundled verified
model catalog, model-capability awareness across the MCP server and the UI (languages, VAD,
translation, prompts), and a loopback Host/Origin guard in the bundled engine. The engine is now
built from this repository (vibe-server v0.6.16-sada.1) instead of the unmodified upstream binary.

| **SHA256SUMS.txt** | SHA-256 of the installer |

    # compare with the Sada_3.4.0_x64-setup.exe line in SHA256SUMS.txt

## Install and upgrade

1. Run **Sada_3.4.0_x64-setup.exe**. It installs per-user under **%LOCALAPPDATA%\Sada\** and needs
   no administrator rights.
2. **SmartScreen note:** the installer is not code-signed, so Windows may show "Windows protected
   your PC". Choose *More info → Run anyway* only for the official build after checking the hash.
3. Upgrading from 3.3.1: run the new installer over the old one; settings, projects and models are
   kept.

## What is in this release

- **Verified model catalog:** Settings → Models lists models from a bundled, verified catalog with
  licence, size, SHA-256 and languages, and downloads are checked against the hash. First entries:
  large-v3-turbo and tiny (MIT) and Hebrew large-v3-turbo-he (Apache-2.0). No model is bundled in
  the installer.
- **Model capability awareness:** the app reads the engine metadata to learn the model class, its
  languages, VAD requirement and translation/prompt support; it reconciles the transcription
  language to the nearest supported one and ensures the Silero VAD model is present before loading
  Nemotron/Parakeet — in Settings, Setup, the transcription queue and the global hotkey.
- **Clearer MCP for agents:** `sada_info` reports `model.capabilities`, and `sada_transcribe` maps
  language codes, passes `--translate`/`--prompt` only when the model supports them, and resolves
  VAD automatically — still without opening any port. Guides: `docs/AGENT-MCP.md`, `docs/AGENT-MCP.ar.md`.
- **Local endpoint hardening:** the bundled engine rejects browser-shaped requests and DNS
  rebinding (non-loopback `Host`, page `Origin`, or a missing `Host`) while native local requests,
  including state-changing routes, keep working only from loopback origins. The app starts the
  engine explicitly on `127.0.0.1` with an ephemeral port, and CI builds the engine from `server/`
  and runs the guard tests on every release. See `SECURITY.md` and `docs/UPSTREAM-PATCHES.md` §9.

## Verification before release

- **Frontend:** 28 test files / 179 tests passed, `pnpm build` (tsc + Vite) passed, i18n audit passed
  with the five new VAD strings present in `en-US` and `ar-IQ`.
- **Rust:** 27 `mcp::` tests and 8 `guard::` tests passed.
- **Live MCP:** Arabic Nemotron transcription with timestamps; Whisper configured as `ar-AR` mapped
  to `ar`; `translate`/`prompt` dropped for Nemotron and the call still succeeded — see
  `docs/VERIFICATION.md`.
- **Live guard matrix:** 200 for native loopback requests, 403 for an external `Host`, a page
  `Origin` and a missing `Host`, including `POST /v1/models/load`.
- The installer is built by CI from the same tree; its digest ships in **SHA256SUMS.txt**.

## Known limitations

- The installer is not code-signed → possible SmartScreen warning.
- No model is bundled; the recommended model is a one-time ~1.6GB download.
- The guard stops web pages and DNS rebinding; a same-user local process can still reach the engine
  API while it runs (a per-run token is the suggested next step).
- GPU acceleration needs a driver with Vulkan 1.1+; otherwise the app runs on the CPU.
- Hallucination is possible on silence or unclear audio; acronyms and numbers can occasionally be
  written out as words.
- Windows only; no macOS/Linux build in this fork.
