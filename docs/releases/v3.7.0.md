# صدى (Sada) 3.7.0 — تغطية اللهجات وقياس توجيه النص المسبق

**صدى** تطبيق تفريغ صوتي وفيديو إلى نص، عربي أولاً، يعمل بالكامل على جهازك بنظام Windows بدون
إنترنت وبدون حساب. هذا الإصدار **إصدار قياس وتوثيق** لا إصدار ميزات: لا تغيير في المحرّك
(**vibe-server v0.6.16-sada.1**) ولا في النماذج ولا في سلوك الواجهة، والمثبّت الناتج مطابق وظيفياً
لـ3.6.0. ما تغيّر هو أداة القياس ووثائقها: صارت تغطي **90 مقطعاً** بخمس شرائح بعد إضافة 15 مقطعاً
خليجياً (سعودي/إنجليزي) و15 مقطعاً تقنياً (مصري/إنجليزي) من مجموعة Perle AI (رخصة MIT، صوت مسجّل
بممثلين أصليين ونصوص بشرية)، وقاست **توجيه النص المسبق (prompt)** فوجدته يضرّ أكثر مما ينفع،
فلم تُشحن أي إعدادات مسبقة. لا تحديث تلقائي ولا قياس عن بُعد ولا حساب.

4. **Windows 10 بلا إنترنت:** ثبّت **WebView2 Evergreen Runtime** مسبقاً (Windows 11 يضمّه).

## ما في هذا الإصدار

- **شريحتا الخليج والتقنية في أداة القياس:** 15 مقطعاً سعودياً (نجدي/حجازي) + إنجليزي و15 مقطعاً
  مصرياً + إنجليزي من مجموعة Perle AI للكلام المتبادل (code-switch)، برخصة MIT، مسجّلة بممثلين
  أصليين من نصوص محادثات مجموعة، ونصوصها المرجعية بشرية لا آلية. الصوت يُنزَّل عند التشغيل ولا
  يُضمَّن في المستودع، والتكرار مثبَّت بمراجعة المجموعة وإزاحة السطر.
- **نتائج كاملة على 90 مقطعاً وخمس نسخ نموذج:** Whisper large-v3-turbo (الافتراضي) 30.27%
  WER إجمالاً (MSA 22.09، لاتيني-مختلط 48.96، مصري 11.03، خليجي **42.74**، تقني **46.18**)،
  ويحتفظ بـ27.3% من الأسماء اللاتينية. Nemotron-3.5 يواصل الفوز على MSA (17.83%) والمصري (9.11%)
  لكنه متأخر 17–19 نقطة على الشريحتين الجديدتين ولا يحتفظ بأي كلمة لاتينية (0%)، فيبقى خياراً
  اختيارياً للإملاء لا الافتراضي. الأرقام القديمة (19.46% على 60 مقطعاً) لا تُقارن مباشرة لأن
  مجموعة المقاطع تغيّرت.
- **قياس توجيه النص المسبق — نتيجة سلبية مسجّلة:** أربع صيغ على 40 مقطعاً بنفس أوزان Turbo:
  بلا نص مسبق 29.38% WER، مسرد عربي+لاتيني 31.92%، مسرد إنجليزي فقط 38.42%، تعليمات عربية فقط
  31.36%. وعلى المجموعة الكاملة يحسّن المسرد الاحتفاظ بالكلمات اللاتينية (التقني 47.1% مقابل
  34.3%) لكنه يكلّف دقة (+1.17 نقطة WER إجمالاً، +6.25 على لاتيني-مختلط). لذلك **لا تُشحن أي
  إعدادات نص مسبق جاهزة**؛ يبقى حقل النص المسبق الاختياري للمستخدم كما هو.
- **مصفوفة التراخيص والفجوات:** docs/P4-PLAN.md يسجّل كل مجموعة فُحصت ورُفضت بسبب ترخيصها (QASR،
  ArSyra، SADA، MADIS5، MASC، Lahgtna، LDC/ELRA، وغيرها) ويُبقي العراقي والشامي **غير مقيسين**
  بصراحة: لا توجد مجموعة مجانية برخصة تجارية ونصوص بشرية حتى 2026-11-18؛ مجموعة مدفوعة قرار شراء
  للمالك لا قرار هندسي.
- **تحسينات أداة القياس:** دعم prompt_file/prompt لكل نموذج، مرشّح --slices، تسجيل بصمة SHA-256
  للنص المسبق، أمثلة نصوص مسبقة ملتزمة، و`build-manifest --reuse` كي لا يعيد توسيع شريحة واحدة
  مسح 110 صفحات من Common Voice تحت حدود المعدّل، مع إعادة محاولة أوسع لأخطاء 429/5xx.

# English

**Sada (صدى)** is an Arabic-first, fully offline speech-to-text desktop app for Windows, forked
from [Vibe](https://github.com/thewh1teagle/vibe) (MIT). Version 3.7.0 is a **measurement and
documentation release, not a feature release**: the engine (**vibe-server v0.6.16-sada.1**), models,
catalogue and UI behaviour are identical to 3.6.0, so the installer is functionally the same app.
What changed is the benchmark and its record: it now covers **90 clips / 5 slices** after adding 15
Gulf (Saudi–English) and 15 technical (Egyptian–English) code-switch clips from the Perle AI corpus
(MIT, audio recorded by native voice actors, human reference transcripts), and it measured initial
**prompt biasing** — which lost, so no prompt preset is shipped. No updater, telemetry or account.

## Install and upgrade

1. Run **Sada_3.7.0_x64-setup.exe**. Per-user install into **%LOCALAPPDATA%\Sada\**; no admin
   rights needed.
2. **SmartScreen:** the installer is not code-signed, so Windows may show "Windows protected your
   PC". Choose *More info → Run anyway* only for the official release after verifying the hash
   (docs/SIGNING.md).
3. Upgrading from 3.6.0 is optional: there is no behaviour change; settings, projects and models are
   kept. If you do not need a new install, staying on 3.6.0 is fine.
4. **Offline Windows 10:** install the **WebView2 Evergreen Runtime** first (Windows 11 ships it).

## What is in this release

- **Gulf and technical benchmark slices:** 15 Saudi (Najdi/Hijazi)–English + 15 Egyptian–English
  code-switch clips from the Perle AI ASR Code-Switch corpus (MIT; audio recorded by native voice
  actors from collected conversational transcripts, human references). Audio is fetched at run time
  and never committed; each clip is pinned by dataset revision and row offset.
- **Full 90-clip results for five model variants:** Whisper large-v3-turbo (default) 30.27% WER
  overall (MSA 22.09, Latin-mixed 48.96, Egyptian 11.03, Gulf **42.74**, technical **46.18**) with
  27.3% of Latin names kept; Nemotron-3.5 still wins MSA (17.83%) and Egyptian (9.11%) but trails by
  17–19 pp on both new code-switch slices and keeps 0% Latin words, so it stays an optional dictation
  entry rather than the default. The old 19.46% figure is not directly comparable — the corpus grew.
- **Prompt-biasing measurement, recorded as a negative result:** four styles on 40 clips with the
  same Turbo weights — no prompt 29.38% WER, Arabic+Latin glossary 31.92%, English-only glossary
  38.42%, Arabic-only instruction 31.36%. On the full corpus the glossary preserves more Latin words
  (technical 47.1% vs 34.3%) but costs accuracy (+1.17 pp WER overall, +6.25 pp on Latin-mixed), so
  **no prompt preset is shipped**; the user-editable prompt field stays unchanged.
- **Licence matrix and remaining gaps:** docs/P4-PLAN.md records every corpus examined and rejected
  with its licence reason (QASR, ArSyra, SADA, MADIS5, MASC, Lahgtna, LDC/ELRA, …) and keeps Iraqi
  and Levantine explicitly **unmeasured**: no free commercial-use corpus with human transcripts was
  found as of 2026-11-18. A paid vendor corpus is an owner purchase decision, not an engineering one.
- **Harness improvements:** per-model prompt_file/prompt, a --slices filter, prompt SHA-256 in result
  metadata, committed prompt texts, and `build-manifest --reuse` so extending one slice does not
  re-walk 110 pages of Common Voice under the viewer's rate limits, plus wider 429/5xx retries.

- **Frontend:** pnpm test — 31 files / 193 tests passed; pnpm build succeeded; i18n audit passed.
- **Rust:** cargo test --release — 101 tests passed; cargo test --release -p vibe-server guard:: —
  8 tests passed.
- **Python:** python -m unittest discover -s tests — 52 tests passed in benchmarks/arabic-asr
  (including the new reuse and prompt-file tests).
- **Measurement:** 450 transcriptions over 90 clips × 5 model variants; raw output in

## Known limitations

- The installer is not code-signed, so SmartScreen may warn until a signing programme in
  docs/SIGNING.md is adopted.
- Offline Windows 10 needs the WebView2 Runtime installed beforehand; the installer does not bundle
  it yet.
- **Iraqi and Levantine remain unmeasured.** The Gulf and technical slices are scripted,
  code-switched speech, not spontaneous dialect speech; the Gulf slice is Saudi only and the
  technical slice is Egyptian only.
- **The ≥90% acronym gate is still not applicable:** none of the 90 reference transcripts contains
  one of the app's tracked acronyms (GPU, PDF, SRT, …), so it is recorded as n/a, not passed;
  Latin-name preservation is the honest proxy.
- 15-clip slices give wide confidence intervals: treat slice deltas below ~2 pp as unresolved unless
  a bootstrap says otherwise.
- There is no app behaviour change in 3.7.0; users who do not need the measurement record can stay
  on 3.6.0.
