# صدى (Sada) 3.5.0 — قياس العربية وقرارات النماذج

**صدى** تطبيق تفريغ صوتي وفيديو إلى نص، عربي أولاً، يعمل بالكامل على جهازك بنظام Windows
بدون إنترنت وبدون حساب. يقدّم هذا الإصدار قياساً عربياً مقيساً بدل التقديرات: مجموعة مرجعية
مثبّتة من 60 مقطعاً بتراخيص تسمح بالاستخدام التجاري، ونظام تقييم MSA/مصرية/مختلطة وأزمنة
وWER/CER، وقرارات نماذج مكتوبة بالأدلة. أبرز نتيجة عملية: **NVIDIA Nemotron 3.5 ASR Streaming
0.6B صار نموذجاً اختيارياً موثّقاً في قائمة النماذج** (OpenMDW-1.1، 496 ميغابايت) لكن Whisper
large-v3-turbo يبقى الافتراضي.

## التثبيت والترقية

1. شغّل **Sada_3.5.0_x64-setup.exe**. التثبيت لكل مستخدم في **%LOCALAPPDATA%\Sada\** ولا يحتاج
   صلاحيات مدير.
2. **تنبيه SmartScreen:** المثبّت غير موقّع رقمياً، فقد يظهر «Windows protected your PC». اضغط
   *More info → Run anyway* فقط للإصدار الرسمي بعد التحقق من البصمة.
3. الترقية من 3.4.0: شغّل المثبّت الجديد فوق القديم؛ الإعدادات والمشاريع والنماذج تبقى كما هي.
   محرّك التفريغ لم يتغيّر في هذا الإصدار (يبقى `vibe-server v0.6.16-sada.1`).

## ما في هذا الإصدار

- **قياس عربي مقيس (E2):** `benchmarks/arabic-asr/` مجموعة أدوات بايثون قياسية بلا تبعيات، تبني
  بيان 60 مقطعاً من مصادر مثبّتة (Common Voice 18 العربية، CC0، وFLEURS `ar_eg`، CC BY 4.0)،
  وتطبّع النص العربي وتقيس WER/CER وحفظ المصطلحات اللاتينية وتغطية الأزمنة وRTF، وتصدر جدولاً
  وحكماً لكل شريحة. الصوت والأوزان لا تدخل Git، والتشغيل بلا شبكة بعد التنزيل الأول.
- **قرارات النماذج موثّقة:** [`docs/MODELS-DECISIONS.md`](../MODELS-DECISIONS.md) يسجّل النتائج
  والأحكام وأوامر إعادة القياس وشروط إعادة النظر.
- **Nemotron اختياري في القائمة:** صار `nemotron-3.5-asr-streaming-0.6b` إدخالاً موثّقاً في
  **الإعدادات ← النماذج ← الحصول على النماذج** — OpenMDW-1.1، 495,831,520 بايت، بصمة
  SHA-256، ويُنزَّل ملف Silero VAD تلقائياً. وصف القائمة يذكر صراحة أنه ينقل المصطلحات اللاتينية
  صوتياً وأنه ليس الافتراضي.
- **قراءة صوتية (TTS): لا.** [`docs/READ-ALOUD.md`](../READ-ALOUD.md) يوثّق أن تثبيت Windows
  العادي لا يضمّ أصواتاً عربية (اختيارية عبر Narrator وتحتاج شبكة وصلاحيات غالباً)، فلم يُكتب أي
  كود قراءة صوتية ويبقى Chatterbox معلّقاً.
- **محرّك ثانٍ: لا (الآن).** تجربة transcribe.cpp + Qwen3-ASR 0.6B على 60 مقطعاً سجّلت WER
  24.38% بلا أزمنة ولا VAD، فرفض الدمج مع إبقاء المتابعة — التفاصيل في ملف القرارات.
- **توثيق محدَّث:** `docs/MODELS.md` و`docs/MODELS.ar.md` (Nemotron اختياري، حدود اللهجات غير
  المقيسة)، `docs/MODELS-COUNCIL.md` §8 ونسخته العربية (دليل القياس)، و`ROADMAP.md`
  (P2 مكتمل)، وسجل CHANGELOG.

## قيود معروفة

- المثبّت غير موقّع رقمياً ← تحذير SmartScreen محتمل.
- Nemotron ينقل المصطلحات اللاتينية صوتياً (GPU ← «جي بي يو») ويحتاج ملف VAD؛ لا يُستخدم افتراضياً.
- شرائح العراقية والخليجية والشامية والكلام التقني عربي/إنجليزي **غير مقيسة** بعد (لا مجموعة
  بترخيص تجاري)؛ `latin-mixed` بديل معلَن، وبوّابة «90% للمصطلحات» غير قابلة للقياس حالياً.
- لا قراءة صوتية ولا محرّك تفريغ ثانٍ في هذا الإصدار (قرارات موثّقة).
- النموذج غير مضمّن ويحتاج تنزيلاً واحداً؛ تسريع GPU يحتاج تعريف بطاقة يوفّر Vulkan 1.1+.
- الهلوسة ممكنة على الصمت أو الصوت غير الواضح؛ الأكرونيمات والأرقام قد تُكتب كلمات أحياناً.
- التطبيق Windows فقط؛ لا إصدار macOS/Linux في هذه الشوكة.

# English

**Sada (صدى)** is an Arabic-first, fully offline speech-to-text desktop app for Windows, forked
from [Vibe](https://github.com/thewh1teagle/vibe) (MIT). Version 3.5.0 replaces estimates with
measured Arabic: a pinned 60-clip benchmark with commercial-use-permissive corpora and a written
decision record. The main practical outcome: **NVIDIA Nemotron 3.5 ASR Streaming 0.6B is now an
optional verified catalogue entry** (OpenMDW-1.1, 496 MB) while Whisper large-v3-turbo remains the
default. No transcription-engine change in this release (still `vibe-server v0.6.16-sada.1`).

    # compare with the Sada_3.5.0_x64-setup.exe line in SHA256SUMS.txt

## Install and upgrade
1. Run **Sada_3.5.0_x64-setup.exe**. It installs per-user under **%LOCALAPPDATA%\Sada\** and needs
   no administrator rights.
2. **SmartScreen note:** the installer is not code-signed, so Windows may show "Windows protected
   your PC". Choose *More info → Run anyway* only for the official build after checking the hash.
3. Upgrading from 3.4.0: run the new installer over the old one; settings, projects and models are
   kept. The transcription engine is unchanged (still `vibe-server v0.6.16-sada.1`).

## What is in this release

- **Measured Arabic benchmark (E2):** `benchmarks/arabic-asr/` is a dependency-free Python harness
  that builds a pinned 60-clip manifest (Common Voice 18 Arabic, CC0; FLEURS `ar_eg` test,
  CC BY 4.0), normalises Arabic text, scores WER/CER, Latin-name/acronym preservation, timestamp
  coverage and RTF per slice, and states a verdict per slice. Audio and weights stay out of git and
  runs are offline after the one-time fetch.
- **Written model decisions:** [`docs/MODELS-DECISIONS.md`](../MODELS-DECISIONS.md) records the
  numbers, the rulings, reproduction commands and the conditions that would reopen each decision.
- **Nemotron is now an optional catalogue entry:** `nemotron-3.5-asr-streaming-0.6b` appears in
  Settings → Models → Get models — OpenMDW-1.1, 495,831,520 bytes, SHA-256 pinned, and the Silero VAD
  file it needs is downloaded automatically. Its description states plainly that it transliterates
  Latin technical terms and that it is not the default.
- **Read-aloud (TTS): no.** [`docs/READ-ALOUD.md`](../READ-ALOUD.md) shows a normal Windows install
  has no Arabic voices (optional Narrator downloads need network and usually elevation), so no
  read-aloud code was written and Chatterbox stays suspended.
- **Second engine: no, for now.** A transcribe.cpp + Qwen3-ASR 0.6B spike over all 60 clips scored
  24.38% WER with no timestamps and no VAD; integration was rejected with keep-learning conditions
  in the decision record.
- **Docs updated:** `docs/MODELS.md` and `docs/MODELS.ar.md` (optional Nemotron, unmeasured
  dialect/technical slices), `docs/MODELS-COUNCIL.md` §8 and its Arabic mirror (evidence log),
  `ROADMAP.md` (P2 complete) and this changelog.

## Known limitations
- The installer is not code-signed → possible SmartScreen warning.
- Nemotron transliterates Latin technical terms (GPU → جي بي يو) and needs the VAD file; it is never
  the default.
- Iraqi, Gulf, Levantine and Arabic/English technical speech are **not measured yet** (no
  commercial-use-permissive corpus); `latin-mixed` is the declared proxy and the ≥90% acronym gate
  is not measurable yet.
- No read-aloud and no second transcription engine in this release (decisions recorded).
- No model is bundled; the recommended model is a one-time download. GPU acceleration needs a driver
  with Vulkan 1.1+.
- Hallucination is possible on silence or unclear audio; acronyms and numbers can occasionally be
  written out as words.
- Windows only; no macOS/Linux build in this fork.
