# صدى (Sada) 3.10.0 — أول إصلاح للواجهة: أربع خطوات ونصوص صادقة

هذا إصدار **واجهة واستخدام**، لا إصدار محرّك: محرّك التفريغ والنماذج وقائمة النماذج وسلوك التفريغ
دون تغيير. ينفّذ قرارات المالك في 19 نوفمبر 2026 بعد تقييم واجهة 3.9.0: **عائلات الإصلاح الأربع كلها
في الموجة الأولى**، مع **نصوص الثقة المقيّدة (V3)** التي تقول ما يمكن إثباته فقط. لم تُنفَّذ هوية
«الصدى» (4.0) ولم تبدأ الموجة الثانية: البوابة القادمة هي **اختبار خمسة مستخدمين عرب**، وهو شرط قبل
3.11 وقبل 4.0.

**ملاحظة الصدق نفسها تنطبق على هذا الإصدار:** المثبّتات ما زالت **غير موقّعة رقمياً**، ولا يوجد
تحديث تلقائي ولا قياس عن بُعد ولا حساب، وتبقى قيود مذكورة أدناه. اختبار الخمسة مستخدمين **لم يُجرَ
بعد**، لذلك لا يدّعي هذا الإصدار تحسيناً مُقاساً في الاستخدام.

## التثبيت والترقية

1. اختر الحزمة: المثبّت الافتراضي للاستخدام الفردي (بلا صلاحيات مدير)، أو MSI للنشر المُدار
   (صلاحيات مدير)، أو مثبّت WebView2 دون اتصال للأجهزة المعزولة.
2. التثبيت لكل مستخدم في %LOCALAPPDATA%\Sada\؛ وMSI يثبّت لكل جهاز في C:\Program Files\Sada\.
3. **SmartScreen:** الملفات غير موقّعة رقمياً (قرار المالك)؛ تحقّق من البصمة أو من بصمة البناء قبل
   تشغيلها. إرشادات القوائم المسموحة للمؤسسات في docs/AV-EDR.md.
4. الترقية من 3.9.0 أو أقدم: ثبّت البناء الجديد فوق القديم؛ تُحفظ الإعدادات والمشاريع والنماذج. لا
   تحديث تلقائي — الإصدار التالي ينشره المستخدم أو المسؤول.
5. النشر المُدار: انظر docs/ENTERPRISE-DEPLOYMENT.md (تثبيت صامت، اكتشاف، سياسة، تنظيف بيانات).

## ما في هذا الإصدار

- **استعادة الثقة عند الفشل (A):** تصنيف أخطاء ثابت الأسبقية (disk → memory → network → audio →
  file → model → managed → unknown) في `error-kind.ts`، ونافذة خطأ واحدة بعنوان ونص وإجراء أساسي
  مرتبط بالسبب: فتح إعدادات النماذج، إعادة محاولة الشبكة، أو إعادة التحميل. السجل الخام خلف إفصاح
  مع **نسخ التفاصيل**؛ **الإبلاغ عن مشكلة** أصبح ثانوياً؛ **إعادة الضبط** انتقلت تحت **متقدّم**.
  وأصبح تغيير السمة يلتقط رفض `setTheme` (مع صلاحية `core:window:allow-set-theme`) فلا يترك
  خطأً غير معالَج.
- **خط النهاية: نسخ الكل وتصدير مُجمَّع (B):** زر **نسخ الكل** أساسي بجانب التصدير مع
  `Ctrl+Shift+C` وتأكيد Toast وإرشاد في التلميح؛ وتبقى الصيغ التسع كلها، لكنها صارت تحت أربع
  مجموعات صغيرة: **نص** (TXT، Markdown)، **ترجمة وتوقيت** (SRT، WebVTT)، **مستند** (HTML، DOCX،
  PDF)، **بيانات** (JSON، CSV). في وضع الدفعات يفتح التصدير قائمة.
- **باب الإعدادات وهرمها (C):** نافذة إعدادات مبنية على Radix `Dialog` — حصر تركيز، `Escape`،
  زر إغلاق حقيقي، واستعادة تركيز عند الإغلاق؛ ترس في ترويسة التطبيق مع `Ctrl+,` وحدث
  `vibe:open-settings`، و`#settings` يفتح النافذة؛ وأربع مجموعات تنقّل (التطبيق، التفريغ،
  الصوت والمساعد، خيارات أخرى) بدل قائمة مسطّحة.
- **الطباعة العربية (D):** قاعدة تتبّع معاكسة — `html[lang^='ar'] * { letter-spacing: 0 }` — مع
  استثناءات صريحة للأحرف الأحادية وأوقات الجداول والتسميات اللاتينية الكبيرة. وأحجام التنزيل
  محاطة بعوازل bidi (U+2066/U+2069) حتى يبقى ترتيب «25 MB من 100 MB» صحيحاً في العربية.
- **نصوص الثقة المقيّدة (V3):** عند الإفلات: «التفريغ يتم على هذا الجهاز — لا يُرفع أي صوت أو نص.»
  و«التنزيل الأول للنموذج يحتاج إنترنت، وبعدها يعمل صدى دون اتصال.»؛ وفي أول تشغيل: «هذا التنزيل
  يحتاج إنترنت مرة واحدة. بعدها يعمل صدى دون اتصال، ولا يُرفع أي صوت أو نص.»؛ وفي خصوصية الإعدادات
  الجملة الكاملة مع استثناء التنزيل. أُزيلت عبارات «لا يغادر جهازك أبداً» و«خصوصية مطلقة» و«آمن
  100%» و«بدون إنترنت» بلا استثناء و«بياناتك ملكك للأبد» من الكتالوجين.
- **تقدّم التنزيل:** شريط `role="progressbar"` بقيم aria، ونسبة حيّة، وحجم «س من ص»، وتقدير وقت
  يظهر فقط بعد تقدّم حقيقي؛ ونص «هذا يحدث مرة واحدة فقط» للتنزيلات غير الخاصة بالروابط.
- **الإتاحة وقت التشغيل:** فحص axe-core 4.14.1 (WCAG 2.2 A/AA) على **35 حالة** (الرئيسية، أقسام
  الإعدادات العشرة، نافذة التصدير) بالإنجليزية والعربية والوضع الداكن: **0 مخالفات**. أُصلحت أسماء
  عناصر التبديل والقوائم، وتباين صف التنقّل المحدد وتذييل الإصدار وشارة الصيغة المحددة، وتطابق اسم
  مُشغّل لغة العرض مع نصّه المرئي.
- **وثائق القرار:** سجل القرارات والإصلاحات في `docs/design/ui-decisions/DECISIONS.md`، واللوحات
  المرئية ولقطات ما بعد الإصلاح في `docs/design/ui-decisions/shots/wave1/`، وعدّة بوابة الخمسة
  مستخدمين في `docs/design/ui-decisions/GATE-KIT.md`.

# English

**Sada (صدى)** is an Arabic-first, fully offline speech-to-text desktop app for Windows, forked
from [Vibe](https://github.com/thewh1teagle/vibe) (MIT). Version 3.10.0 is a **UI/UX repair
release, not an engine release**: the engine, models, model catalogue and transcription behaviour
are unchanged. It implements the owner's 19 November 2026 decisions after the 3.9.0 UI/UX
critique: **all four Wave-1 repair families**, with the **V3 scoped truth-only copy** that states
only what can be proven. The "Echo" identity (4.0) is **not** in this release and Wave 2 has not
started; the next gate is a **five-user Arabic test**, required before 3.11 and 4.0.

The same honesty applies to this release: the installers are still **unsigned**, there is no
auto-updater, telemetry or account, and the limitations below still hold. The five-user gate has
**not been run yet**, so this release does not claim a measured usability improvement.

## Install and upgrade

1. Pick a package: the default installer for individual users (no admin), the MSI for managed
   deployment (admin rights), or the offline WebView2 installer for isolated machines.
2. Per-user install into %LOCALAPPDATA%\Sada\; the MSI installs per-machine into
   C:\Program Files\Sada\.
3. **SmartScreen:** the files are not code-signed (owner decision); verify the hash or the build
   provenance before running them. Allow-listing guidance for managed environments is in
   docs/AV-EDR.md.
4. Upgrading from 3.9.0 or older: install the new build over the old one; settings, projects and
   models are kept. There is no auto-update — the next release is deployed by the user or
   administrator.
5. Managed deployment: see docs/ENTERPRISE-DEPLOYMENT.md (silent install, detection, policy, data
   cleanup).

## What is in this release

- **Trust and failure recovery (A):** a fixed-precedence error classification in `error-kind.ts`
  (disk → memory → network → audio → file → model → managed → unknown) and one error dialog with
  a kind-specific title and body, plus a contextual primary action: open model settings, retry a
  network step, or reload. The raw log sits behind a disclosure with an accessible **Copy
  details**; **Report issue** is demoted to secondary and **Reset** moved under **Advanced**. The
  window `setTheme` call now catches its rejection and has the `core:window:allow-set-theme`
  capability, so a theme change can no longer leave an unhandled promise error.
- **The finish line: copy all and grouped export (B):** a filled-primary **Copy all** button next
  to Export, `Ctrl+Shift+C`, the full transcript as plain text, a toast confirmation and a
  tooltip hint. All nine formats stay, grouped under four small headings: **Text** (TXT,
  Markdown), **Captions & timing** (SRT, WebVTT), **Document** (HTML, DOCX, PDF) and **Data**
  (JSON, CSV). In batch mode Export opens a menu.
- **Settings door and hierarchy (C):** the Settings modal is rebuilt on Radix `Dialog` — focus
  trap, `Escape`, a real close button and focus restore on close; a gear in the app header with
  `Ctrl+,`, a `vibe:open-settings` event, and `#settings` opens the dialog on mount; four
  navigation groups (App, Transcription, Voice & assistant, More options) with headings instead of
  one flat list.
- **Arabic typography (D):** an inverse tracking rule — `html[lang^='ar'] * { letter-spacing: 0 }`
  — with explicit exceptions for mono/tabular time and uppercase Latin labels, so Arabic letters no
  longer inherit the Latin UI tracking; download sizes are wrapped in Unicode bidi isolates
  (U+2066/U+2069) so "25 MB of 100 MB" keeps its order in Arabic.
- **V3 scoped truth-only copy:** at the drop point — "Transcription happens on this computer — no
  audio or text is uploaded." and "The first model download needs the internet; after that Sada
  works offline."; on first run — "This download needs the internet once. After that Sada works
  offline, and no audio or text is uploaded."; and the full sentence, with the download exception,
  in Settings → Privacy. The banned phrases ("never leaves your device", "absolute privacy",
  "100% safe", "offline" without the first-download exception, ownership absolutes) are gone from
  both catalogues.
- **Download progress:** a `role="progressbar"` with aria values, a live percent, an "x of y"
  size and an ETA that appears only after enough real progress; "This happens only once…" for
  non-URL downloads.
- **Runtime accessibility:** an axe-core 4.14.1 audit (WCAG 2.2 A/AA tags) across **35 states**
  (idle, all 10 Settings sections, the export dialog) in English, Arabic and dark mode found
  **0 violations**. Fixed: accessible names for switches and Radix select triggers, contrast of the
  selected Settings nav row, the version footer and the selected export-format badge, and the
  display-language trigger name containing its visible label.
- **Decision records:** the decisions and implementation record are in
  `docs/design/ui-decisions/DECISIONS.md`, the boards and post-fix screenshots in
  `docs/design/ui-decisions/shots/wave1/`, and the five-user gate kit in
  `docs/design/ui-decisions/GATE-KIT.md`.

## Known limitations

- **The installers are not code-signed**, so SmartScreen may warn until the staged signing path is
  enabled (docs/SIGNING.md). There is no certification and no external audit.
- **The five-user gate has not been run yet:** 3.10 must not be read as a measured usability
  improvement until it completes. It is required before 3.11 and 4.0.
- **The Windows screen-reader check has not been done:** an axe audit cannot see screen-reader
  behaviour.
- **The installed (Tauri) build was not audited for accessibility:** the evidence is from the dev
  mock; auditing the installed build is still needed.
- **Acceptance rows B–E are unexecuted** (offline Windows 10, CPU-only, AVX-only, SSE4.2 without
  AVX): the maintainer has no such hardware/VM.
- **Focus restoration after the dialog closes** was not confirmed in the headless harness (the
  focus trap and Escape are confirmed).
- **The ETA needs calibration on a real download**, and the progress fill stays LTR in Arabic
  (to be measured in the gate).
- **No at-rest encryption of transcripts:** use BitLocker (or equivalent) for sensitive data.
