# صدى (Sada) 3.2.2 — Arabic-first

**صدى** تطبيق تفريغ صوتي وفيديو إلى نص، عربي أولاً، يعمل بالكامل على جهازك بنظام Windows
بدون إنترنت وبدون حساب. هذا أول إصدار عام مبني على [Vibe v3.2.2](https://github.com/thewh1teagle/vibe)
(رخصة MIT) مع تعريب كامل، واتجاه RTL، وافتراضيات عربية.

## التحميل

| الملف | الوصف |
| --- | --- |
| `Sada_3.2.2_x64-setup.exe` | مثبّت Windows x64 (NSIS، غير موقّع رقمياً) |
| `SHA256SUMS.txt` | بصمة SHA-256 للمثبّت |
| `THIRD-PARTY-NOTICES.md` · `NOTICE` · `LICENSE` | الترخيص والإسناد وإشعارات الأطراف الثالثة |

تحقّق من الملف بعد التنزيل:

```powershell
Get-FileHash .\Sada_3.2.2_x64-setup.exe -Algorithm SHA256
# قارن الناتج بسطر Sada_3.2.2_x64-setup.exe في SHA256SUMS.txt
```

## التثبيت

1. شغّل الملف `Sada_3.2.2_x64-setup.exe`. التثبيت لكل مستخدم في `%LOCALAPPDATA%\Sada\` ولا يحتاج صلاحيات مدير.
2. **تنبيه SmartScreen:** المثبّت غير موقّع رقمياً، فقد يظهر «Windows protected your PC». اضغط
   *More info → Run anyway* فقط إذا نزّلت الملف من هذا الإصدار الرسمي وتحقّقت من بصمته.
3. افتح **صدى** من قائمة ابدأ. يفتح مباشرة بالعربية ومن اليمين إلى اليسار.
4. أول مرة: نزّل نموذج Whisper من **الإعدادات ← النماذج** (المقترح للعربية `large-v3-turbo`، ~1.6GB)،
   أو اختر ملف `ggml-*.bin` موجوداً على جهازك. النموذج لا يُشحن مع المثبّت.

المتطلبات: Windows 10/11 (64-bit) ومساحة قرص كافية للنموذج (~1.6GB للنموذج المقترح).

## ما في هذا الإصدار

- **عربي أولاً:** واجهة عربية كاملة (704/704 نصاً، `ar-IQ`)، RTL، خط IBM Plex Sans Arabic،
  أرقام غربية وتواريخ عراقية، وافتراضيات تفريغ عربية (لغة `ar`، بلا ترجمة، حرارة 0، beam 5).
- **تفريغ محلي بالكامل:** محرّك Whisper (عبر `vibe-server` / whisper.cpp) و`ffmpeg` مضمّنان؛
  لا تُرسل التسجيلات إلى أي خادم.
- **تصحيح نص عربي:** توحيد الفواصل والعلامات العربية، واستعادة الأكرونيمات اللاتينية الشائعة
  (GPU/CPU/PDF/SRT/API/FFmpeg/Whisper) داخل النص العربي.
- **تصدير متعدد:** SRT وVTT وTXT وHTML وPDF (بخط عربي) وDOCX وJSON.
- **إملاء** عبر اختصار لوحة مفاتيح، **تسجيل** من الميكروفون وصوت النظام، و**دفعات** ملفات.
- **خصوصية:** بلا قياسات، بلا تحديث تلقائي، بلا حساب، وبلا مرحّل هاتف (مخفي في هذا الإصدار).
- **إصلاح أول تشغيل:** النافذة الرئيسية تفتح بالعربية من أول لحظة (أُصلح سباق لغة بين النوافذ).

# English

**Sada (صدى)** is an Arabic-first, fully offline speech-to-text desktop app for Windows, forked
from [Vibe v3.2.2](https://github.com/thewh1teagle/vibe) (MIT). This is its first public release.

## Download

- `Sada_3.2.2_x64-setup.exe` — Windows 10/11 x64 installer (NSIS, unsigned)
- Verify the installer against `SHA256SUMS.txt` before running it.
- License and attribution files are attached next to the installer.

## Install

1. Run the installer. It installs per-user into `%LOCALAPPDATA%\Sada\` and does not need admin rights.
2. SmartScreen may warn because the installer is not code-signed; choose *More info → Run anyway*
   only for this official release after checking the SHA-256.
3. Launch Sada from the Start Menu — it opens in Arabic, right-to-left.
4. Download a Whisper model once from **Settings → Models** (suggested: `large-v3-turbo`, ~1.6GB) or
   pick an existing `ggml-*.bin`. Models are not bundled.

## What is in this release

- Full Arabic UI (704/704 strings, `ar-IQ`), RTL layout, IBM Plex Sans Arabic, Western digits,
  Iraqi date formats, and Arabic transcription defaults.
- Fully local Whisper transcription (`vibe-server` / whisper.cpp) with bundled FFmpeg; no audio
  leaves the machine, no telemetry, no updater, no account.
- Arabic transcript normalization (Arabic punctuation, common Latin acronym restoration).
- Export to SRT, VTT, TXT, HTML, Arabic PDF, DOCX and JSON.
- Dictation hotkey, microphone/system-audio recording, batch files.
- Tests: 26 files / 130 tests passing. See `docs/VERIFICATION.md` for evidence and limitations.

## Known limitations

Unsigned installer (SmartScreen warning), model download required (~1.6GB), occasional silence
hallucinations and acronym/number normalization gaps, PDF text extraction may confuse automated
extractors, Windows-only.
