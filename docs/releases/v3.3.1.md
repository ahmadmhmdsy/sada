# صدى (Sada) 3.3.1 — محرّك أحدث وتوثيق GPU

**صدى** تطبيق تفريغ صوتي وفيديو إلى نص، عربي أولاً، يعمل بالكامل على جهازك بنظام Windows
بدون إنترنت وبدون حساب. يرفع هذا الإصدار محرّك التشغيل إلى **vibe-server v0.6.16**، ويثبّت
نموذج فصل المتحدثين الجديد **Nemotron-3-Diarization**، ويوثّق أخيراً **تسريع GPU عبر Vulkan**
الذي كان موجوداً في المحرّك دون شرح، ويحدّث FFmpeg المضمّن إلى 9.0.2.

## التحميل

| الملف | الوصف |
| --- | --- |
| **Sada_3.3.1_x64-setup.exe** | مثبّت Windows x64 (NSIS، غير موقّع رقمياً) |
| **SHA256SUMS.txt** | بصمة SHA-256 للمثبّت |
| **THIRD-PARTY-NOTICES.md** · **NOTICE** · **LICENSE** | الترخيص والإسناد وإشعارات الأطراف الثالثة |

تحقّق من الملف بعد التنزيل (PowerShell):

    Get-FileHash .\Sada_3.3.1_x64-setup.exe -Algorithm SHA256
    # قارن الناتج بسطر Sada_3.3.1_x64-setup.exe في SHA256SUMS.txt

## التثبيت والترقية

1. شغّل **Sada_3.3.1_x64-setup.exe**. التثبيت لكل مستخدم في **%LOCALAPPDATA%\Sada\** ولا يحتاج
   صلاحيات مدير.
2. **تنبيه SmartScreen:** المثبّت غير موقّع رقمياً، فقد يظهر «Windows protected your PC». اضغط
   *More info → Run anyway* فقط للإصدار الرسمي بعد التحقق من البصمة.
3. الترقية من 3.3.0: شغّل المثبّت الجديد فوق القديم؛ الإعدادات والمشاريع والإضافات تبقى كما هي.

> **نموذج فصل المتحدثين يتغيّر تلقائياً:** النموذج القديم (Sortformer) لم يعد مستخدماً. عند أول
> تشغيل لخاصية المتحدثين ينزّل صدى الملف الجديد (108 MB) ويترك القديم على القرص دون حذفه، لكنه
> لم يعد يظهر في قائمة النماذج. لا حاجة لأي خطوة يدوية.

## ما في هذا الإصدار

- **محرّك أحدث (v0.6.16):** إصلاحات انهيار على الملفات الكبيرة وأخطاء Vulkan، ودعم معالجات
  قديمة بلا AVX (SSE4.2 فقط)، وإعادة بناء الجمل والفقرات، وإعادة محاولة الأسطر المتكررة. هذه
  هي الإصلاحات التي تجعل دعم GPU آمناً عملياً.
- **فصل متحدثين جديد:** نموذج **Nemotron-3-Diarization Q8_0** (GGUF) بدل Sortformer ONNX:
  ملف واحد، ومتوافق مع المحرّك الجديد، ويوسم شرائح النص بأرقام المتحدثين كما في السابق.
- **توثيق GPU أخيراً:** قسم **تسريع GPU (اختياري)** في README وREADME العربي، وقسم
  **GPU acceleration (runtime)** في docs/BUILDING.md، وتحديث docs/DEBUG.md: اختيار الجهاز في
  **الإعدادات ← النماذج ← العتاد**، معنى «تلقائي»، الرجوع إلى المعالج عند غياب Vulkan، وإعادة
  المحاولة عند نفاد ذاكرة البطاقة وتذكّر النموذج.
- **FFmpeg 9.0.2:** النسخة المضمّنة في المثبّت (GPLv3) مع تحديث إشعار المصدر.
- **لا نماذج مضمّنة، ولا تبعيات جديدة، ولا قياسات:** يبقى المثبّت هو نفسه بلا نموذج، والمحرّك
  الجديد هو نفس ثنائي upstream. نموذج فصل المتحدثين الاختياري يُنزَّل وقت الاستخدام بترخيص
  NVIDIA OpenMDW-1.1.

## التحقق قبل النشر

- **تكرار عربي مطابق:** المقاطع الأربعة (فصحى، أخبار، حوار عراقي، مزج تقني) أعطت النص نفسه
  حرفياً مع المحرّك القديم v0.6.10 على نموذج large-v3-turbo.
- **أزمنة وتصدير:** خرج SRT وVTT بشرائح وأزمنة صحيحة.
- **فصل المتحدثين:** النموذج الجديد أعاد وسم 12 من 12 شريحة على المقطع المدمج (متحدثان).
- **مسارات أخرى:** Nemotron 3.5 ASR ما زال يُحمّل ويعمل خلف Silero VAD؛ مسار CPU فقط
  (no_gpu) أكمل التفريغ بنجاح.
- اختبارات الواجهة وبناء pnpm build واختبارات Rust: انظر [docs/VERIFICATION.md](../VERIFICATION.md).
- المثبّت يبنى بواسطة CI من نفس المصدر؛ بصمته في **SHA256SUMS.txt** المرفق مع الإصدار.

## قيود معروفة

- المثبّت غير موقّع رقمياً ← تحذير SmartScreen محتمل.

# English

**Sada (صدى)** is an Arabic-first, fully offline speech-to-text desktop app for Windows, forked
from [Vibe](https://github.com/thewh1teagle/vibe) (MIT). Version 3.3.1 moves the pinned engine to
**vibe-server v0.6.16**, adopts the new **Nemotron-3-Diarization** speaker model, documents the
**Vulkan GPU acceleration** the engine already shipped, and updates the bundled FFmpeg to 9.0.2.

## Download

- **Sada_3.3.1_x64-setup.exe** — Windows 10/11 x64 installer (NSIS, unsigned)
- Verify the installer against **SHA256SUMS.txt** before running it.
- License and attribution files are attached next to the installer.

## Install and upgrade

1. Run the installer. It installs per-user into **%LOCALAPPDATA%\Sada\** and needs no admin
   rights.
2. SmartScreen may warn because the installer is not code-signed; choose *More info → Run anyway*
   only for this official release after checking the SHA-256.
3. Upgrading from 3.3.0: run the new installer over the old one; settings, projects and the
   installed model stay where they are.

> **The speaker model changes automatically.** The old Sortformer file is retired. The first time
> diarization runs, Sada downloads the new 108 MB GGUF and leaves the old file on disk untouched —
> it simply no longer appears in the model list. No manual step is required.

## What is in this release

- **Newer engine (v0.6.16):** fixes for crashes on large files and Vulkan errors, support for
  pre-AVX CPUs (SSE4.2 only), sentence and paragraph reconstruction, and repeated-line retries.
  These are the fixes that make shipping a GPU option defensible.
- **New diarization model:** **Nemotron-3-Diarization Q8_0** (GGUF) replaces the Sortformer ONNX
  file — one file, built for the current engine, and it labels transcript segments with speaker
  numbers exactly as before.
- **GPU finally documented:** a new **GPU acceleration (optional)** section in both READMEs, a
  **GPU acceleration (runtime)** section in docs/BUILDING.md, and an updated docs/DEBUG.md:
  the device picker in **Settings → Models → Hardware**, what **Auto** means, the CPU fallback when
  Vulkan is missing, and the out-of-memory retry-and-remember behaviour.
- **FFmpeg 9.0.2:** the bundled GPLv3 decoder, with its source offer updated.
- **No model bundled, no new dependency, no telemetry:** the installer is unchanged in shape and
  the engine is the upstream binary. The optional diarization model downloads at runtime under
  NVIDIA OpenMDW-1.1.

## Verification

- **Arabic parity:** the four clips (MSA, news, Iraqi dialogue, technical mix) produced exactly
  the same text on large-v3-turbo with v0.6.16 as they did on v0.6.10.
- **Timings and export:** SRT and VTT output returned correctly timed segments.
- **Diarization:** the new model labelled 12/12 transcript segments on the combined clip (two
  speakers).
- **Other paths:** Nemotron 3.5 ASR still loads and runs behind Silero VAD; the CPU-only
  (no_gpu) path still transcribes.
- Frontend tests, pnpm build and Rust tests: see [docs/VERIFICATION.md](../VERIFICATION.md).
- The installer is built by CI from this tree; its SHA-256 is in **SHA256SUMS.txt** on the
  release.

## Known limitations

- The installer is not code-signed, so SmartScreen may warn.
- Models are not bundled: one download (~1.6 GB for the recommended model; ~108 MB for the
  speaker model the first time diarization runs).
- GPU acceleration needs a driver with Vulkan 1.1+; without it the app runs on the CPU.
- Hallucination is possible on silence or unclear audio; acronyms and numbers can come out as
  words.
- Windows only; this fork ships no macOS/Linux build.
