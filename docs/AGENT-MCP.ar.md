# صدى كخادم MCP

أُضيف في **3.3.0**. صدى تطبيق تفريغ صوتي عربي أولاً ويعمل دون إنترنت، وهذه الوثيقة تشرح خادم MCP
المدمج في ملف التطبيق نفسه: يتيح للوكلاء (agents) تفريغ الصوت وقراءة ما حفظه المستخدم من نصوص،
دون تشغيل خادم ولا فتح منفذ ولا فتح نافذة التطبيق.

- **النقل:** stdio فقط. لا يُفتح منفذ ولا يُجرى أي اتصال شبكي.
- **الواجهة:** غير مطلوبة. تبدأ العملية وتخدم JSON-RPC وتنتهي عند إغلاق stdin.
- **الخصوصية:** الصوت لا يغادر الجهاز؛ لا حساب ولا قياسات ولا مفتاح API.
- **الفكرة:** Voicebox يمنح الوكلاء صوتاً، وصدى يمنحهم أذناً عربية على جهاز المستخدم.

## البدء السريع

خادم MCP هو ملف التطبيق المثبَّت مع المعامل **--mcp**:

~~~text
%LOCALAPPDATA%\Sada\Sada.exe --mcp
~~~

اختبار سريع دون أي عميل — إطار JSON-RPC واحد في كل سطر، وإطار واحد لكل رد:

~~~json
{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26"}}
{"jsonrpc":"2.0","id":2,"method":"tools/list"}
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"sada_info","arguments":{}}}
~~~

## تسجيل الخادم

**Claude Code:**

~~~text
claude mcp add sada -- "C:/Users/you/AppData/Local/Sada/Sada.exe" --mcp
~~~

**Codex** — في **~/.codex/config.toml**:

~~~toml
[mcp_servers.sada]
command = "C:/Users/you/AppData/Local/Sada/Sada.exe"
args = ["--mcp"]
~~~

**أي عميل يقبل إعداد JSON** (Claude Desktop وCursor وWindsurf وغيرها):

~~~json
{
  "mcpServers": {
    "sada": {
      "command": "C:/Users/you/AppData/Local/Sada/Sada.exe",
      "args": ["--mcp"]
    }
  }
}
~~~

أعد تشغيل العميل بعد تعديل إعداده. الملف المثبَّت موجود في **%LOCALAPPDATA%\Sada\**، والبناء من
المصدر ينتج **desktop/src-tauri/target/release/vibe.exe** (ونسخة Tauri تحزمه باسم **Sada.exe**).

## الأدوات

| الأداة | الوظيفة |
| --- | --- |
| **sada_transcribe** | تفريغ ملف صوت أو فيديو محلي بالنموذج المُعد، وإرجاع نص عربي منسّق افتراضياً. |
| **sada_transcripts** | سرد النصوص المحفوظة من الأحدث، مع المسار ومعاينة. |
| **sada_transcript** | قراءة نص محفوظ؛ الأحدث افتراضياً، مع أزمنة وترقيم متحدثين اختياريين. |
| **sada_info** | الإصدار والنموذج والمحرك ومجلد النصوص ومسار الإعدادات، وهل كل ملف موجود. |

### sada_transcribe

| المعامل | النوع | ملاحظات |
| --- | --- | --- |
| path | نص، مطلوب | مسار مطلق لملف محلي (mp3، wav، m4a، mp4، mkv، ...). تُرفض الروابط. |
| language | نص | رمز لغة بحرفين (**ar**) أو بصيغة BCP-47 (**ar-AR**)، ويُقارب إلى أقرب لغة يدعمها النموذج المضبوط؛ و**auto** يطلب من النموذج الكشف. الافتراضي لغة التطبيق (العربية). |
| translate | منطقي | ترجمة الكلام إلى الإنجليزية بدل التفريغ بلغة المصدر. مغلق افتراضياً، ويُتجاهل مع النماذج التي لا تدعم الترجمة (Nemotron وParakeet). |
| timestamps | منطقي | إضافة [البداية --> النهاية] لكل مقطع. مغلق افتراضياً. |
| normalize | منطقي | تنظيف صدى للنص العربي. افتراضياً **true**. |
| model | نص | مسار نموذج ggml بديل (متقدم). |
| prompt | نص | توجيه أولي للمحركات التي تقبله — Whisper حالياً (متقدم). |
| threads | عدد | خيوط المعالجة؛ 0 أو غيابه يستخدم إعداد التطبيق. |
| enhance_audio | منطقي | تسوية الصوت بـ FFmpeg المرفق أولاً. مغلق افتراضياً. |
| vad_model | نص | مسار نموذج Silero VAD. يُحدَّد تلقائياً بجوار النموذج المضبوط للمحركات التي تشترط VAD (Nemotron وParakeet)؛ مرّره للتجاوز فقط (متقدم). |

مثال:

~~~json
{"jsonrpc":"2.0","id":10,"method":"tools/call","params":{"name":"sada_transcribe","arguments":{"path":"C:/Users/you/Desktop/meeting.mp3","timestamps":true}}}
~~~

قبل التشغيل، يطلب **sada_transcribe** بيانات النموذج من المحرك فيكيّف الطلب: تُقارَب رموز اللغة إلى
قائمة النموذج، ويُمرَّر **--translate** و**--prompt** فقط عندما يعلن النموذج دعمهما، ويُحدَّد نموذج Silero
VAD تلقائياً عندما يشترطه المحرك. وتُعاد إعدادات التفكيك نفسها (beam size والحرارة والخيوط والتوجيه)
فتطابق النتيجة ما يظهر في التطبيق للملف نفسه.

### sada_transcripts

| المعامل | النوع | ملاحظات |
| --- | --- | --- |
| limit | عدد | من 1 إلى 50؛ الافتراضي 10. |
| folder | نص | مجلد نصوص آخر (متقدم). |

يُرجع JSON فيه **folder** و**total** و**shown** ومصفوفة **transcripts**؛ لكل عنصر **name** و
**created_at** و**language** و**path** و**audio** الاختياري و**preview**، مرتبة من الأحدث حسب
الطابع الزمني في أسماء المجلدات والملفات.

### sada_transcript

| المعامل | النوع | ملاحظات |
| --- | --- | --- |
| path | نص | ملف **transcript.vibe.json** أو مجلد المشروع. يُحذف لقراءة الأحدث. |
| timestamps | منطقي | بادئة زمنية [البداية --> النهاية]. مغلق افتراضياً. |
| speakers | منطقي | وسم المتحدثين [speaker 1] و[2]... مغلق افتراضياً. |
| include_summary | منطقي | إضافة آخر ملخص ذكي محفوظ. مغلق افتراضياً. |

الأزمنة في السجل المحفوظ بسنتي الثانية (centiseconds)، وتُعرض هنا بصيغة HH:MM:SS.mmm.

### sada_info

بلا معاملات. يُرجع JSON عن هذا التثبيت: الإصدار، والنموذج، والمحرك، وFFmpeg، ومجلد النصوص، ومسار
الإعدادات، وهل كل مسار موجود فعلاً. ويضم **model.capabilities** قدرات النموذج المضبوط: المحرك
(**engine**)، وقائمة اللغات المدعومة، واشتراط **requires_vad**، ودعم **translation** و**text_prompts**.
ابدأ به عند أي خطأ «نموذج مفقود» أو «محرك مفقود».

## الافتراضيات العربية

- **اللغة الافتراضية** من **transcription.modelOptions.lang** في إعدادات التطبيق. ملف التعريف الجديد
  يضع **ar**، ويمكن تغييرها من الواجهة. مرّر **language: "auto"** للكشف التلقائي.
- **الترجمة مغلقة** افتراضياً، لأن تحويل العربية إلى الإنجليزية ليس الحالة الشائعة لمستخدمي صدى.
- **التنظيف العربي** هو نفسه المستخدم في الواجهة: علامات ترقيم عربية بدل ASCII، وإزالة المسافات قبل
  الترقيم، واستعادة الاختصارات الشائعة (GPU وCPU وPDF وSRT وVTT وJSON وAPI وFFmpeg وWhisper) حين
  يكتبها whisper.cpp بحروف عربية. التنظيف بلا فقدان ويتحمّل التكرار; مرّر **normalize: false** لرؤية
  خرج المحرك الخام.
- **نص RTL** يُعاد كما هو دون إضافة أي محارف اتجاه.

## كيف تُحلّ المسارات

ملف الإعدادات بالترتيب:

1. **--config <path>** بعد **--mcp**؛
2. متغير البيئة **SADA_CONFIG_PATH**؛
3. **%APPDATA%/app.sada.desktop/app_config.json**؛
4. **%LOCALAPPDATA%/app.sada.desktop/app_config.json**؛
5. مجلدات Vibe القديمة (**github.com.thewh1teagle.vibe** و**com.vibe.desktop**) لمن كان يستخدم
   النسخة الأصلية.

النموذج: معامل **model** ثم **model.path** في الإعدادات.

المحرك: **SADA_ENGINE** ثم **vibe-server.exe** بجوار ملف التطبيق (هناك يضعه المثبّت)، ثم مجلد
**desktop/src-tauri/binaries/** في نسخ التطوير، وأخيراً PATH.

FFmpeg: **VIBE_SERVER_FFMPEG_PATH** ثم بجوار المحرك/التطبيق؛ لا يُحتاج إلا لصيغ لا يفكّها المحرك أو
مع **enhance_audio**.

مجلد النصوص: **transcription.projectsPath** ثم **SADA_TRANSCRIPTS_DIR** ثم **Documents/Sada** (مع
مراعاة إعادة توجيه OneDrive). وهو المجلد نفسه الذي تعرضه صفحة المشاريع.

## البروتوكول

- الإصدارات: **2025-06-18** و**2025-03-26** و**2024-11-05** (يُتفاوض عليها؛ والمجهول يعود للأقدم).
- الطرق: **initialize** و**notifications/initialized** و**ping** و**tools/list** و**tools/call**،
  و**resources/list** و**prompts/list** تُجاب بقائمتين فارغتين للعملاء الذين يتحسسانها.
- القدرات: الأدوات فقط.
- الطلبات تُعالج واحداً بعد الآخر: التفريغ قد يستغرق دقائق، وتوازي طلبين يتنازع على ملف النموذج.
- stdout للإطارات فقط؛ خرج المحرك يُحتفظ به، والتشخيص إلى stderr.
- رمز الخروج 0 عند إغلاق stdin.

## الأمان والخصوصية

- **لا منفذ ولا شبكة:** النقل عبر stdin/stdout لعملية يبدأها عميل MCP.
- **ملفات محلية فقط:** تُرفض روابط http(s) وwww برسالة توضيحية بدل تنزيلها.
- **لا أسرار في النتائج:** يُقرأ من الإعدادات مسار النموذج واللغة ومجلد النصوص فقط؛ مفاتيح مزوّدي
  الملخصات وبقية القيم لا تظهر أبداً في نتيجة أداة.
- **لا رفع صلاحيات ولا تثبيت:** يستخدم الخادم مجلدات المستخدم نفسها.

## استكشاف الأخطاء

| العرض | الحل |
| --- | --- |
| «لا يوجد نموذج مضبوط في صدى» أو «النموذج المضبوط غير موجود» | افتح صدى ← الإعدادات ← النماذج ونزّل نموذجاً (المقترح large-v3-turbo) أو اختر ملفاً، ثم أعد المحاولة، أو مرّر مسار **model** صريحاً. |
| «محرك vibe-server.exe غير موجود» | أعد تثبيت صدى، أو اضبط **SADA_ENGINE** على مسار المحرك. |
| نتيجة فارغة أو «لم يُرجع نصاً» | قد يكون الملف صامتاً أو غير قابل للفك؛ جرّب **enhance_audio: true** وتأكد من FFmpeg في **sada_info**. |
| لغة خاطئة | مرّر **language: "ar"** صراحة; الكشف التلقائي يخطئ في المقاطع القصيرة. |
| **isError: true** | نص الخطأ يشرح الحل، و**sada_info** يبيّن المسار المفقود. |
| العميل لا يبدأ الخادم | استخدم المسار الكامل لـ **Sada.exe** في إعداد العميل وأعد تشغيله. |

## التحقق من البناء

اختبارات Rust المدمجة (من **desktop/src-tauri**):

~~~text
cargo test --release
cargo test --release mcp::
cargo test --release arabic::
~~~

تغطي إطارات البروتوكول وتعريفات الأدوات الأربع ومسح النصوص وعرضها والمنظّف العربي وحل الإعدادات.
وللتحقق الشامل: نزّل نموذجاً حقيقياً، واضبط **model.path** في إعداد مؤقت، ثم استدعِ
**sada_transcribe** عبر **--config** وتأكد من خرج عربي على مقطع معروف.
