DECISION
اختر B الآن، واحجز C للإصدار 4.0

B is the only direction that fixes the RTL shell and the trust point without a rebrand. It costs 2–3 days and is reversible at token level. C is stronger but premature: it changes the product's silhouette and should follow positioning, not lead it.

If you want zero visual riskA
If identity is this release's goalB + C brief
If a rebrand is wanted nowC — deferred by council
WHAT IDENTITY IS NOT

No logo, no rebrand, no font licensing, no asset pipeline. Identity here means the decisions a user feels on every screen: direction, accent, density, and the one motif that makes Sada recognisable.

Windows are illustrative prototypes, not implementation specs
