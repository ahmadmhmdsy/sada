Question 04 · Trust copy

Which sentence can survive the truth?

Absolute claim is false on first runRecommendation: scoped two-sentence version

Sada downloads its model once, over the network, before it can work offline. Any absolute “nothing ever leaves” promise placed on the idle screen is contradicted by the very next screen a new user sees. The fix is not to soften the promise — it is to scope it to the thing that is true: transcription.

Scope the promise to transcription, not to the entire product lifecycle. That sentence stays true through future local features; anything networked gets its own copy.

APPROVED WORDING TO IMPLEMENT (V3)
عند منطقة الإفلات: «التفريغ يتم على هذا الجهاز — لا يُرفع أي صوت أو نص.»
سطر ثانٍ أصغر: «التنزيل الأول للنموذج يحتاج إنترنت، ثم يعمل صدى دون اتصال.»
في الإعدادات (إصلاح الجملة الحالية): «بعد تنزيل النموذج، يعمل صدى على هذا الجهاز بالكامل: لا تحليلات ولا قياس عن بُعد ولا حساب.»
في أول تشغيل: «جارٍ تنزيل النموذج مرة واحدة. بعدها يعمل صدى دون إنترنت.» + الحجم والوقت المتبقي.
WORDS WE WILL NOT USE
لا يغادر جهازك أبداً خصوصية مطلقة آمن 100% بدون إنترنت (بدون استثناء التنزيل) بياناتك ملكك للأبد

Every banned phrase fails the same test: true on screen 1, false on screen 2. Scoped copy is not weaker marketing; it is the only version that can be repeated after the download screen.

Recommendation: approve V3 copy as the two-sentence standard, and fix the existing Settings sentence in the same pass
