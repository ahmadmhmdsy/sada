Arabic-first transcription, on your own computer.

Sada turns audio and video into text on Windows, with Arabic first: a right-to-left interface, Arabic transcription defaults, IBM Plex Sans Arabic typography and Arabic-aware transcript cleanup. The Whisper engine runs locally — nothing is uploaded. Since 3.3.0 a built-in MCP server gives agents Arabic ears with no port and no account.

Why Sada?

Most transcription apps treat Arabic as a translation target. Sada inverts that and builds the Windows experience around Arabic first.

1

Arabic-first and RTL

Display language ar-IQ, transcription language ar, translation off, temperature 0 and beam 5, Arabic typography and Arabic PDF export.

2

Fully local transcription

whisper.cpp engine with bundled FFmpeg; audio and video never leave your computer.

3

Whisper models

Use any ggml-*.bin model. Recommended for Arabic: large-v3-turbo (~1.6GB). Models are not bundled with the installer.

4

Many export formats

SRT, VTT, TXT, HTML, Arabic PDF with an embedded font, DOCX and JSON.

5

Dictation and recording

A global dictation shortcut types into any app, plus microphone and system-audio recording.

6

Private by design

No analytics, no updater, no account, no phone relay. The network is used only for actions you request.

7

Agent-ready (MCP)

The app executable is a local MCP server over stdio: Sada.exe --mcp transcribes files, lists and reads saved transcripts and reports install details for Claude Code, Codex and other MCP clients.

Install in four steps

The app installs per user and needs no administrator rights. The model is downloaded once.

  1. Download the installerFrom the releases page: Sada_3.3.1_x64-setup.exe.
  2. Verify the checksumCompare the SHA-256 with the attached SHA256SUMS.txt.
  3. Run the installerInstalls into %LOCALAPPDATA%\Sada — no admin rights. SmartScreen may warn because it is unsigned.
  4. Download a model onceSettings → Models: large-v3-turbo (~1.6GB) or an existing ggml-*.bin file.
SmartScreen: The installer is not code-signed. Choose More info → Run anyway only after verifying the checksum.

Private by design

Sada collects nothing about you — there is nothing to collect.

No analyticsNo trackers, no crash reporting, no account. The upstream Aptabase client is removed from source.
No auto-updateNo silent updates and no update server. Updates are manual from the releases page.
Your data stays yoursAudio, transcripts and settings live in your own user profile. Nothing is sent to a server.

Frequently asked questions

Is Sada free?

Yes. MIT-licensed source and a free Windows installer, with no account, subscription or ads.

Does it work offline?

Yes, after a one-time Whisper model download. Transcription is fully local; the network is used only for actions you request.

Does it support Iraqi Arabic?

Whisper handles Iraqi Arabic as part of Arabic, and the Arabic cleanup normalizes punctuation. Accuracy depends on the model and audio; start with large-v3-turbo.

Why does Windows warn about the installer?

The installer is not code-signed. Verify the published SHA-256 checksum, or build the app from source yourself.

Can AI agents use Sada?

Yes, since 3.3.0. Sada.exe --mcp is a local MCP server over stdio: transcribe a file, list and read saved transcripts, and report install details. Register it in Claude Code or any MCP client. Local only: no port, no account, no network. See docs/AGENT-MCP.md.

How is it different from Vibe?

Sada is a fork of Vibe v3.2.2 with full Arabic localization and RTL, Arabic defaults, Arabic PDF export, and removal of telemetry, auto-update and the phone relay, plus its own name and icon, and since 3.3.0 a built-in MCP server for agents.

Where are my files?

Settings, logs and projects live in %APPDATA%\app.sada.desktop; the model and WebView data in %LOCALAPPDATA%\app.sada.desktop. Nothing is sent to a server.
